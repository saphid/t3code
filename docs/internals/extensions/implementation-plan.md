## Public/private decisions

“Public” means a versioned contract subject to grants, not unrestricted access. Keep host implementation private while exposing every operation needed to replace the corresponding built-in.

| Existing family                                                | Decision                                          | Boundary                                                                                                                                    |
| -------------------------------------------------------------- | ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| Workspace tree, text reads/writes, search, media               | Public through scoped adapters                    | Host resolves environment/project/thread root. No arbitrary caller cwd; full native size/format behavior must be supported.                 |
| File/URL/diff presentation and surface lifecycle               | Public                                            | Typed resource references, open/reveal/activate/close and explicit unavailable states.                                                      |
| Composer, comments, context and turn enrichment                | Public through client adapters                    | Explicit target and supported operations; no raw stores or alteration of persisted message truth.                                           |
| Theme, settings, keybindings, clipboard, notifications         | Public supported subset                           | Registered commands and preferences; client/gesture capability checks; no unrestricted settings or OS bridge.                               |
| Terminal, browser, source-control operations                   | Public through scoped adapters                    | Include writes and controls required for parity, not just observers. Raw PTY processes, cookies, credentials and native IPC remain private. |
| Agents, sessions, work, approvals and checkpoints              | Public through orchestration adapter              | Preserve meaning and authority; raw event stores, provider protocol and checkpoint storage remain private.                                  |
| Provider discovery and supported harness operations            | Public authorized subset                          | Read capabilities/status and request supported operations; credentials, installation internals and raw process handles stay private.        |
| Pairing, credentials, database/event writes, transport tickets | Private                                           | Host performs these operations for authorized calls; never delegate its root identity to a package.                                         |
| Plugin APIs, dependencies, provider choice and health          | Public typed discovery; authorized administration | Reuse broker/resolver. Registration conveys no authority; no feature-ID switch in the broker.                                               |

Do not expose entire EnvironmentApi/LocalApi objects. Derive small domain contracts from existing operations. Host services can remain the default provider; installed plugins may provide approved shared contracts under explicit selection policy. Client-only operations must use the same invocation/authority model with a scoped client provider—not an extra bag of private callbacks.

## Proposed contract slices

Names below are proposed; P01 checks collisions and freezes exact schemas before executable changes. Keep existing API IDs/versions and package formats compatible. Do not silently enlarge existing result limits or alter filePresentationApi v1.

| Proposed contract                                       | Minimal operations and shape                                                                                                                                                              | Host implementation / owner                                                                                 |
| ------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |

| t3.file/resource-presentation@1                         | open(ResourceRef, optional line/range/navigation intent) -> surface descriptor/restore state                                                                                              | Same selection path; retain filePresentationApi v1 and provide a compatibility entry for existing consumers |
| t3.ui/surfaces                                          | discover/open/activate/close; handles scoped to owner/context; close protection                                                                                                           | Extension host and installed presentation runtime                                                           |
| t3.ui/preferences, t3.ui/clipboard, t3.ui/notifications | supported theme/editor preferences; bounded clipboard operations; show/dismiss notices                                                                                                    | Client adapters with platform capability discovery                                                          |

| t3.source-control/repository, t3.review/diff            | status/refs/diff; authorized stage/unstage/commit/branch/PR operations and capability discovery                                                                                           | Existing VcsDriver/GitWorkflow/review/PR services                                                           |
| t3.orchestration/*                                      | bounded status/subscribe, navigate, start/cancel/settle, approval response, checkpoint inspect/diff/restore                                                                               | Separate V1/V2 adapters; advertise each supported operation                                                 |
| t3.harness/*                                            | connected instance/capability discovery and authorized physical-session operations                                                                                                        | Existing provider adapters; separate provider capability from plugin permission                             |

ResourceRef identifies environment, project/thread as appropriate, kind and opaque host resource ID. It must not embed a connection origin or pretend V1 turn IDs are V2 run IDs. View handles are ephemeral; domain resources and versioned saved view state survive view disposal. Scope changes invalidate old handles/results. Package update/uninstall does not transfer opaque state to a different provider.

Use existing cancellation, caller identity, grants, bounded schema validation and generation checks. Writes never fail over automatically. An acknowledgement is not settlement; cancellation after dispatch does not establish rollback. Prefer existing domain receipts, with explicit unsupported/unknown recovery where unavailable. Durable domain-state support is proved per adapter, not inferred from durable package installation.

Current Node/client plugin execution is trusted code, not a security sandbox. Broker tests establish mediated-call authority, not prevention of ambient filesystem/network access. Do not broaden that claim during migration.
