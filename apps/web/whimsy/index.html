A GUIDE FOR THE NEXT AGENT

Make the useful thing
a little more lovable.

01 / Start with a real moment.

Name the exact action and its true state. Pairing accepted. Project recognized. Turn finished. Write the reverse and failure states first.

02 / Give the detail a job.

Recognition, explanation, reassurance or expression. If the only purpose is “make it fun,” sharpen the idea.

03 / Respond once. Then rest.

Use a short bounded motion. No idle loops, confetti for routine work, fake progress, added waiting or sound by default.

04 / Keep a quiet version.

Reduced motion gets the final static state. Preserve contrast, focus, keyboard access and text meaning. Never rely on color alone.

05 / Follow the whole feature.

Check every entry point, client and connection mode. Hydration, reconnection and background recovery must not replay old celebrations.

06 / Show the complete behavior.

Capture the trigger, transition, settled state and reversal. Crop to include the relevant context. Test the real client; label fixtures honestly.
